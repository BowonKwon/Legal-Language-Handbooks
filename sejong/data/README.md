|---|---|
| `mapping.csv` | 자질 대응표 — 언어 · 소리 · 환경마다 2층 · 1층 표기, 출처층, 근거 등급, 근거 · 반대 근거 문헌 id |

| `m3-inventory-{es,ru,zh,vi}.tsv` | 확장 표본의 분절음 빈도 |
| `sample-*.tsv` · `pairs-*.tsv` | 지표 계산에 쓴 표제어 표본과 대립쌍(`pairs-zh-sub-p3.tsv` 는 판 3 이 더한 경성 ↔ 3성 쌍) |
