# 세종의 글자로 보는 외래어 표기 — 판 2

외국어를 배우는 한국어 화자에게 그 말의 소리를 한글로 안내하는 보조 표기와, 그 표기의 근거를 공개하는 연구 사이트다. 『훈민정음』 전통이 실제로 만든 꼴 가운데 유니코드에 있는 36개만 쓰고, 표마다 국립국어원 「외래어 표기법」 표기(0층)를 함께 둔다. 판 2는 스페인어 · 러시아어 · 중국어를 다룬다.

- 첫 면: `index.html`
- 데이터: `data/` — 대응표 `mapping.csv`, 참고문헌 `bib-public.json`(CSL-JSON), 규칙 명세 `rules.md`, 지표 표본·대립쌍 12개, 지표 결과 `metrics-v2.json`, 분절 빈도표 `m3-inventory-*.tsv`
- 엔진: `code/`
- 웹폰트: `assets/fonts/` — Noto Sans KR · Noto Serif KR 부분집합(옛한글 첫가끝 자모와 방점 포함)과, 법률 외국어 자습서가 옛한글에만 불러 쓰는 자모 전용 `sj-jamo.woff2`
