# Par ces motifs — 법전과 법정의 프랑스어

**A2 수준에서 시작하는 한국 법률가를 위한 법률 프랑스어 자습서** · 권보원 엮음 · 대외판 1.0(2026. 10. 15.)

GitHub에서 `index.html` 을 누르면 책 대신 코드가 보입니다. 책은 위 화면본 링크로 여십시오. 소리는 장별로 처음 누를 때 내려받습니다(장당 2~7 MB).

제목 «Par ces motifs»(이상의 이유로)는 프랑스 판결이 이유를 끝내고 주문으로 넘어갈 때 쓰는 말입니다. 2019년 파기원(Cour de cassation)이 판결 문체를 바꾼 뒤에도 남았습니다 — 2023~2025년 파기원 판결 3,093건 중 3,076건에 이 문구가 있습니다(DILA 공개 데이터 전수 집계). 책은 그 판결 문체를 빌려 왼쪽 여백에 문단 번호를 달았고, 첫머리에는 『파르마의 수도원』을 쓰며 아침마다 민법전을 두세 쪽씩 읽었다는 스탕달의 편지 초안을 실었습니다.

20장·390 표제어입니다. 표제어마다 쉬운 예문·실무 예문·**조문 또는 판결 원문**, 문형 상자, 「한국이라면?」 대조, 긴 원문의 구문 분해가 붙어 있고, 장마다 「말해 보기」·「설명해 보기」 대화와 「따라 말하기」 10문장(보통·느린 속도)이 있습니다.

## 어떻게 만들었나

- **프랑스 조문**은 프랑스 법률정보청(DILA)의 LEGI 데이터(레지프랑스와 같은 원천, Licence Ouverte 2.0)의 현행 판본과 자동 대조했습니다(민법·형법·형사소송법·민사소송법·법원조직법전·행정재판법전·지식재산법전·행정관계법전·1958년 헌법). **판결**은 DILA의 파기원(CASS)·국사원(JADE) 공개 데이터, **헌법·인권선언·헌법위원회 결정**은 헌법위원회 게시본, **옛 원전**은 두 판본(그중 하나는 원본 스캔)과 대조했습니다. 번역은 엮은이의 것입니다.
- **한국 조문**은 국가법령정보센터 현행 본문과 대조했습니다(2026. 10. 2. 시행 개정 반영).
- **독립 AI 검토**(Codex)의 지적을 원문으로 다시 확인해 반영했습니다. 확인하지 못한 서술은 싣지 않았습니다.
- **발음 표기**는 Wiktionnaire(프랑스어판)를 따르고, Lexique 3.83으로 2차 대조했습니다. **합성음**은 Coqui TTS `tts_models/fr/css10/vits`(모델 BSD-3-Clause; 학습 녹음은 CSS10 프랑스어 — LibriVox 낭독, 퍼블릭 도메인)로 만든 기계 합성음입니다. 사람의 발음·억양과 다를 수 있습니다.
