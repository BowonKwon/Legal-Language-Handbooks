# Anspruch — 청구권으로 읽는 법률 독일어

**입문을 조금 지난(A2~B1) 한국 법률가를 위한 법률 독일어 자습서** · 권보원 엮음 · 대외판 1.0(2026. 10. 16.)

- [화면본(HTML, 소리 단추)](https://bowonkwon.github.io/Legal-Language-Handbooks/anspruch/)
- [인쇄본(PDF, 852쪽)](anspruch-v1.0.pdf)
- [Anki 덱(표제어 371장, 합성음 포함)](anspruch-v1.0.apkg)

GitHub에서 `index.html` 을 누르면 책 대신 코드가 보입니다. 책은 위 화면본 링크로 여십시오. 소리는 장별로 처음 누를 때 내려받습니다.

제목 «Anspruch»(청구권)는 독일 민법이 사건을 생각하는 단위입니다. 「누가 누구에게 무엇을 어떤 근거로 청구할 수 있는가(Wer will was von wem woraus?)」 — 이 책은 그 물음을 뼈대로 독일 법령·판결·원전을 원문으로 읽습니다. 19장·371 표제어이며, 표제어마다 쉬운 예문·실무 예문·**조문 또는 판결 원문**, 문형 상자, 「한국이라면?」 대조, 긴 원문의 구문 분해가 붙어 있고, 장마다 가짜 친구·한국 대조·문법 되살리기·말하기 코너와 확인 문제가 있습니다.

## 어떻게 만들었나

- **독일 법령**은 연방법무부·juris의 gesetze-im-internet.de 조문 페이지와, **스위스**는 Fedlex, **오스트리아**는 RIS, **연방헌법재판소 결정**은 법원 공식 페이지의 해당 문단과 자동 대조했습니다. **원전**은 Deutsches Textarchiv(Savigny, CC BY-SA 4.0)와 괴팅겐 대학 디지털화 센터(Jhering)·1946년 SJZ 스캔(Radbruch)을 쪽 단위로 대조했습니다. 번역은 엮은이의 것입니다.
- **한국 조문**은 국가법령정보센터 현행 본문과 대조했습니다.
- **독립 AI 검토**(Codex)의 지적을 원문으로 다시 확인해 반영했습니다. 법원 명칭은 법원행정처 외국 법원 명칭 가이드라인을 따랐습니다.
- **발음 표기**는 Wiktionary(de)를 따르고 DWDS로 확인했습니다. **합성음**은 Coqui TTS `tts_models/de/thorsten/vits`(모델 Apache 2.0; 녹음 Thorsten-Voice, CC0)로 만든 기계 합성음입니다. 사람의 발음·억양과 다를 수 있습니다.
